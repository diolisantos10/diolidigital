# Tráfego Pago — Células Meta/WhatsApp e TikTok

## Decisão aprovada pelo CEO

O departamento de Tráfego Pago e Performance começará com uma estrutura enxuta e expansível:

- um Gerente de Tráfego Pago e Performance acima de todo o departamento;
- uma célula Meta Ads & WhatsApp;
- uma célula TikTok Ads;
- um coordenador por célula;
- a estrutura operacional atual de seis agentes replicada dentro de cada célula;
- novas células somente quando demanda, complexidade ou verba justificarem.

Esta pasta é um pacote de construção. Ela não ativa agentes, não altera produção, não movimenta verba e não autoriza campanhas.
