Vídeo: confira a palestra sobre relatórios do workshop de 2019

A geração de relatórios de dados de performance é uma parte integral dos aplicativos da API Google Ads. Com as opções flexíveis de geração de relatórios dessa API, você pode coletar dados de performance para todos os recursos. Isso inclui tudo, desde uma campanha inteira até um conjunto de palavras-chave que acionaram seu anúncio.

Este guia descreve as etapas necessárias para criar e enviar uma consulta à API Google Ads para receber dados. Para mais informações sobre relatórios, a documentação de referência de relatórios descreve os recursos que podem ser consultados na API Google Ads usando GoogleAdsService.SearchStream ou GoogleAdsService.Search.
