Criar uma Conta do Google

Você precisa de uma Conta do Google para criar um projeto no Console de APIs do Google. Se já tem uma, continue o processo.

Usar o Perfil da Empresa

Para esta documentação da API, pressupomos que você já tenha usado o Perfil da Empresa e conheça os conceitos de programação e formatos de dados da Web.

Se você ainda não usou esse produto, teste a interface do usuário antes de começar a programar.

Criar um projeto no Console de APIs do Google

Antes de enviar solicitações às APIs do Perfil da Empresa, você precisa usar o Console de APIs do Google para criar um projeto e pedir acesso às APIs para esse projeto. Se quiser criar um projeto, acesse o Console de APIs do Google. Clique em Criar projeto, insira um nome e clique em Criar.

Criar uma conta da organização

Para criar uma conta da organização, acesse a Central de Ajuda do GBP.

Pedir acesso às APIs

Para ativar seu projeto e acessar as APIs, siga as instruções abaixo:

Acesse o Console de APIs do Google e selecione o projeto que você criou para usar com o Perfil da Empresa.
Para descobrir o ID dele, confira a coluna ID do projeto.
Agora, os pedidos de acesso às APIs devem ser feitos pelo formulário de contato das APIs do GBP. Selecione "Pedido de acesso básico às APIs" no menu suspenso e informe os dados solicitados.
Depois que o pedido for analisado, vamos enviar um e-mail de acompanhamento a você.
Após a aprovação, consulte Configuração básica para ativar as APIs do Perfil da Empresa no seu projeto.
