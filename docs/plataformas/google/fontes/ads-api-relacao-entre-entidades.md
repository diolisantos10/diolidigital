Introdução à API do Google Ads

A API Google Ads é a interface programática do Google Ads, usada para gerenciar contas e campanhas grandes ou complexas. É possível criar um software que gerencia contas do nível do cliente até o nível da palavra-chave. Os casos de uso típicos incluem:

gerenciamento de contas automático
geração de relatórios personalizada
gerenciamento de anúncios com base no inventário
Gerenciamento da estratégia de Lances Inteligentes
A API Google Ads é o produto certo para mim?

O Google oferece vários produtos para ajudar a automatizar contas do Google Ads. Use a tabela a seguir para identificar o produto que melhor atende aos seus requisitos.

Cenário	Recomendação
Sou um desenvolvedor que quer criar um software personalizado ou fazer a integração com a API Google Ads e tenho experiência em gerenciar infraestrutura de servidor e banco de dados.	Use a API Google Ads.
Sou um desenvolvedor que quer escrever uma lógica personalizada, mas prefiro não gerenciar a infraestrutura de servidores.	Use os scripts do Google Ads.
Não sou desenvolvedor, mas quero aprender programação básica para automatizar o Google Ads.	Use os scripts do Google Ads.
Sou um analista de dados que precisa baixar relatórios do Google Ads para análise off-line ou de data warehouse.	Use o serviço de transferência de dados do BigQuery para transferências do Google Ads.
Estou criando modelos de mix de marketing (MMM) e preciso de dados de anúncios do Google Ads.	Use a MMM Data Platform. Embora muitos anunciantes usem a API Google Ads para extrair dados, ela não é ideal para o desenvolvimento da MMM.
Quero gerenciar o Google Ads em massa sem escrever código.	Use regras automatizadas, uploads em massa ou o Google Ads Editor.
