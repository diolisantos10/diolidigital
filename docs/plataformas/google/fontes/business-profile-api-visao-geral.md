Ter uma presença on-line é importante para os comerciantes, porque a maioria dos clientes na Web usa um mecanismo de pesquisa para encontrar empresas e fazer compras nos sites delas. Os clientes que fazem buscas na Pesquisa Google ou no Maps encontram os Perfis de Empresas nessas duas plataformas e podem clicar neles.

O Perfil da Empresa oferece uma maneira rápida e fácil para negócios, produtos, marcas, artistas e organizações gerenciarem a presença on-line com o Google.

Quando um proprietário de uma pequena empresa mostra aos clientes em potencial o diferencial dela, as chances de atrair novos clientes no Google são maiores. Os proprietários de empresas podem criar facilmente uma ficha compartilhando fotos, horário de funcionamento, um link para o site e atualizações em tempo real.

Nas fichas, os clientes também encontram mais informações sobre a empresa e podem fazer avaliações e compartilhar fotos da experiência deles com os produtos ou serviços.

APIs do Perfil da Empresa 

As APIs do Perfil da Empresa são uma interface de programação que ajuda aos desenvolvedores a criar aplicativos para gerenciar os dados das unidades e contas do Perfil da Empresa.

Com elas, os comerciantes ou representantes deles podem gerenciar como os dados aparecem no Google e controlar quem administra essas informações. Os dados criados pelo usuário, como fotos, postagens e avaliações, podem ser gerenciados nas APIs.

Para recuperar as informações de empresas locais e oferecer reconhecimento de local aos usuários finais, consulte a documentação da Plataforma Google Maps.

Se você é desenvolvedor e quer criar aplicativos que gerenciem seus dados do Perfil da Empresa ou se usa a API AdWords para gerenciar extensões de local manuais, recomendamos que se inscreva nas APIs do Perfil da Empresa.

Qualificação para uso das APIs Business Profile

As APIs Google Business Profile não estão disponíveis para todos os usuários. Qualquer usuário que exija acesso às APIs precisam atender aos requisitos a seguir:

O usuário precisa ter uma Conta do Google válida.
O usuário precisa ter um motivo legítimo para solicitar o acesso às APIs. Consulte a seção das políticas da API GBP para saber mais sobre as APIs.
O usuário precisa ter um projeto ativo do Google Cloud.
É necessário que o URL do site da empresa seja válido.

Você pode solicitar o acesso às APIs do Perfil da Empresa aqui.

Recursos das APIs

As APIs do Perfil da Empresa oferecem vários dos mesmos recursos que a interface do usuário. As atualizações do Google nas APIs ocorrem da mesma maneira que na interface do usuário. Para mais detalhes sobre as atualizações do Google, consulte Gerenciar atualizações do Google.

As restrições de limite de taxa se aplicam às APIs do Perfil da Empresa. Para mais informações, consulte Limites de uso.
