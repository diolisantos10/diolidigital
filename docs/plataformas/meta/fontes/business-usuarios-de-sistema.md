Usuários do sistema

Realize ações programáticas e automatizadas em objetos de anúncio ou Páginas, ou compre anúncios de forma programática. Os usuários do sistema representam servidores ou um software que fazem chamadas de API para ativos gerenciados por um Gerenciador de Negócios.

Usar a ferramenta Gerenciador de Negócios é a maneira mais fácil e rápida de criar um usuário do sistema. Consulte Adicione um usuário do sistema ao Gerenciador de Negócios.

Para realizar ações para uma pessoa que gerencia uma conta de anúncios, a conduza pelo fluxo oAuth padrão do Facebook e obtenha um token de acesso do usuário. Caso você tente usar tokens de usuário do sistema para trabalhar com objetos de anúncio ou Páginas em nome de um usuário real do seu software, não será possível vincular esse usuário a tais ações, a menos que ele seja guiado por meio do Login do Facebook.
