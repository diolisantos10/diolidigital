Get started

Welcome to TikTok Accounts API! With developers in mind, we make accessing and using our API very easy. Only a few simple steps are required to gain access and start managing your TikTok Account. Below are the steps needed to take before making your first API call and some useful resources to help you quickly integrate with TikTok Accounts API.

Note
To ensure proper use of the Accounts API, starting March 20, 2026 at 00:00 (GMT+0), developers must complete the Accounts API Access Application Form before submitting a new developer app or requesting a scope increase that includes the "TikTok Accounts" permission scope. Please follow the instructions carefully and provide clear, accurate information to help facilitate the application review process. For more details on Accounts API use cases, please refer to the Accounts API documentation.

Step by step workflow
Create a TikTok For Business account.
Register as a developer.
Create a developer app.
Authorization.
Authentication.
Make your first API call: You can use TikTok API for Business Postman collection to easily test your integration without impacting your real TikTok Account.
