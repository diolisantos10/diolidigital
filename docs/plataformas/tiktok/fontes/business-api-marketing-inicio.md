Get started

Welcome to Marketing API! With developers in mind, we make accessing and using our API very easy. Only a few simple steps are required to gain access and start managing your TikTok marketing products. Below are the steps needed to take before making your first API call and some useful resources to help you quickly integrate with Marketing API.

Step-by-step workflow
Create a TikTok For Business account.
Register as a developer.
Create a developer app.
Authorization.
Authentication.
Make your first API call: You can use TikTok API for Business Postman collection to easily test your integration without impacting your real TikTok for Business account.
Useful resources

To discover other helpful resources that can assist you in getting started, such as rate limits, app permissions, and sandbox, please refer to this comprehensive Get Started Guide.
