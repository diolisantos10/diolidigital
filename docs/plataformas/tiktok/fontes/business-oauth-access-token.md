Obtain a long-term access token

Use one of the two endpoints to generate a long-term access token: /oauth2/access_token/ and /oauth/token/.

A long-term access token is a type of token that you can obtain after receiving authorization from an ad account, a Business Center account, or a TikTok One Creator Marketplace account. The token does not expire. If you want to revoke a long-term access token, use /oauth2/revoke_token/.

Note
/oauth2/access_token/ only supports Content-Type as application/json, while /oauth/token/ supports Content-Type as application/json or application/x-www-form-urlencoded.

/oauth2/access_token/

Use this endpoint to get a long-term access token that does not expire.

The only supported Content-Type value is application/json. To generate an access token via Content-Type as application/x-www-form-urlencoded, see the /oauth/token/ section below.

/oauth/token/

Use this endpoint to get an access token. The supported Content-Type values are application/x-www-form-urlencoded and application/json. This is a new endpoint in TikTok API for Business v1.3.

Request

Endpoint https://business-api.tiktok.com/open_api/v1.3/oauth/token/

Method POST

Header

Field	Data Type	Description

Content-Type

Request message type
Accepted format: [application/x-www-form-urlencoded, application/json]

Parameters

Field	Data Type	Description

client_id
Required
	
string
	
ID of your developer app.

To find the App ID, navigate to My Apps > App Detail > Basic Information.

client_secret
Required
	
string
	
Secret of your developer app.

To find the Secret, navigate to My Apps > App Detail > Basic Information.

code
Required
	
string
	
The authorization code (auth_code) generated by your Advertiser authorization URL.

The code is valid for one hour and can only be used once.

To find out how to get the authorization code based on the type of API you use, see the "Authorization URL" row in Comparing authorization for different APIs.

grant_type
Required
	
string
	
The way of generating the access token.

The allowed enum value: authorization_code (To generate the access token by authorization code).
Example
Content-Type as application/x-www-form-urlencoded
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/oauth/token/' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'grant_type=authorization_code' \
--data-urlencode 'client_id={{client_id}}' \
--data-urlencode 'client_secret={{client_secret}}' \
--data-urlencode 'code={{code}}'

Content-Type as application/json
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/oauth/token/' \
--header 'Content-Type: application/json' \
--data-raw '{
    "grant_type": "authorization_code",
    "client_id": "{{client_id}}",
    "client_secret": "{{client_secret}}",
    "code": "{{code}}"
}'
