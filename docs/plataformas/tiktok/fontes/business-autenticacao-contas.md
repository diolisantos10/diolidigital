Authentication

With the authorization code you receive after authorization by the TikTok account user, you can make a request to the following endpoint to get a TikTok account access token for subsequent API requests, as well as a TikTok account refresh token for access token renewal.

To get the TikTok account permission scopes that are authorized by the TikTok account user, you can pass the generated access token to /tt_user/token_info/get/.

Access Token Expiry

The TikTok account access token is valid for one day. Once a TikTok account access token has expired, you need to make a request to this endpoint to renew the access token. Remember to pass in the refresh_token for a token renewal request.

Refresh Token Expiry

The TikTok account refresh token is valid for one year. If the refresh token expires, the developer needs to request the user to re-authorize their application via the user authorization workflow.

Authentication
To get or renew the TikTok account access token, you can use /tt_user/oauth2/token/ and /tt_user/oauth2/refresh_token/ respectively. The endpoints require redirect_uri for better security.
To revoke the TikTok account access token, use /tt_user/oauth2/revoke/.
Obtain a TikTok account access token

Use this endpoint to get a TikTok account access token.

Request

Endpoint https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/token/

Method POST

Header

Field	Data Type	Description

Content-Type
required
	
string
	
Request message type
Allowed format: "application/json"

Parameters

Field	Data Type	Description

client_id
required
	
string
	
ID of your developer app.

To find the App ID, navigate to My Apps > App Detail > Basic Information.

client_secret
required
	
string
	
Secret of your developer app.

To find the Secret, navigate to My Apps > App Detail > Basic Information.

grant_type
Required
	
string
	
The way of generating the access token.

The allowed enum value:
authorization_code: To generate the access token by authorization code.

auth_code
Required
	
string
	
The authorization code (auth_code) generated by your TikTok account holder authorization URL.

The code is valid for 10 minutes and can only be used once.

To find out how to get the authorization code based on the type of API you use, see the "Authorization URL" row in Comparing authorization for different APIs.

redirect_uri
Required
	
string
	
The redirect URL which the client will be directed to.

Its value must be the same as the TikTok account holder redirect URL set in the app.
Example
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/token/' \
--header 'Content-Type: application/json' \
--data '{
    "client_id":"{{client_id}}",
    "client_secret":"{{client_secret}}",
    "grant_type":"authorization_code",
    "auth_code":"{{auth_code}}",
    "redirect_uri":"{{redirect_uri}}"
}'

Revoke a TikTok account access token

Header

client_secret
Required
	
string
	
Secret of your developer application.

To find the Secret, navigate to My Apps > App Detail > Basic Information.

access_token
Required
	
string
	
The TikTok account access token that you want to revoke.

You can either create a new access token via /tt_user/oauth2/token/ or obtain a renewed access token via /tt_user/oauth2/refresh_token/ .
Example
curl --location --request POST 'https://business-api.tiktok.com/open_api/v1.3/tt_user/oauth2/revoke/' \
--header 'Content-Type: application/json' \
--data '{
    "client_id":"{{client_id}}",
    "client_secret":"{{client_secret}}",
    "access_token":"{{access_token}}"
}'
