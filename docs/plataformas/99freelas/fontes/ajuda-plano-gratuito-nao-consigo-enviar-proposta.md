# Sou profissional do plano gratuito e não consigo enviar proposta. Como faço?

Provavelmente você está tentando enviar uma proposta em um projeto recente. Os projetos no 99Freelas ficam disponíveis somente para assinantes durante as primeiras 24 horas. Após esse período, todos os profissionais cadastrados, assinantes ou não, poderão enviar suas propostas caso ainda tenha conexões disponíveis.
