O seu projeto não será aprovado caso se enquadre nos motivos abaixo:

-
Conteúdo não permitido: quando há conteúdo não permitido na descrição do projeto (informações de contato, orçamento, solicitação de testes não remunerados, etc)

-
Ilegal: está solicitando algo que é ilegal ou que será utilizado para fins não permitidos

-
Não Permitido: se o tipo de trabalho não é permitido no 99Freelas

-
Pagamento Comissionado*: projetos com pagamentos parciais ou totais via comissão não são permitidos.

-
Poucos detalhes: os freelancers precisam saber detalhes para que possam enviar as suas propostas. Seja o mais específico possível.

-
Projeto Confuso: não está claro o que é pedido no projeto

-
Projeto Duplicado: publicou um projeto muito parecido ou idêntico a pouco tempo. Se você está publicando outro projeto igual pois deseja contratar mais de um freelancer para o mesmo projeto, basta publicar o projeto em modo privado .

-
Proposta pra trabalhar: se o seu objetivo é encontrar trabalhos, altere o seu perfil para o de freelancer.

-
Requer trabalho não pago: todo trabalho deve ser pago. Não são aceitos projetos que requerem testes não pago por exemplo.

-
Vaga de emprego*: nosso site é somente para trabalhos temporários. Não podemos te ajudar a encontrar profissionais para ocupar cargos na sua empresa.

-
Sem demanda: está recrutando profissionais para parceria ou para demandas futuras.

-
Trabalhos acadêmicos: o seu trabalho não pode ser feito por outra pessoa. Valorize a sua educação. Somente é permitido ajudas.

-
Conteúdo impróprio: o conteúdo do projeto não é adequado à plataforma.

-
Troca de trabalho: não permitimos permuta.

-
Vaga de emprego: nosso site é somente para trabalhos temporários. Não podemos te ajudar a encontrar profissionais para ocupar cargos na sua empresa

-
Propagandas: não permitimos nenhum tipo de propaganda.

* Alguns projetos que se enquadrem nesse motivo podem ser aprovados caso sejam considerados adequados à plataforma.
