# Operação Salvaguarda — Instagram Story V1

**Estado:** ordem de recuperação pronta para execução pelo Diretor.

**Objetivo único:** provar uma corrente funcional que começa no pedido do cliente e termina com um Story real, visual e aprovável no portal.

Este pacote não autoriza apagar departamentos, afrouxar portões, publicar em conta real nem ampliar escopo. A recuperação preserva a arquitetura existente e conecta um único recorte vertical antes de qualquer nova expansão.

## Fonte de verdade

Durante esta operação, este diretório governa o recorte `instagram_story_estatico_v1`. Documentos antigos continuam válidos como histórico, mas não podem ampliar nem reinterpretar esta missão.

## Resultado que vale

`done`, `Deliverable` textual, cartão vazio, descrição de arte ou deploy verde **não são entrega**.

Só vale como sucesso quando o cliente fictício ou parceiro consegue:

1. pedir um Story;
2. receber uma imagem final 1080×1920 no portal;
3. abrir a peça em tamanho legível;
4. aprovar, pedir ajuste ou recusar;
5. baixar o arquivo final;
6. e a auditoria consegue provar cada transição pelo banco e pelos artefatos.

Publicação automática na Meta é uma fase separada e só entra depois de conexão, permissão e formato terem sido comprovados.
