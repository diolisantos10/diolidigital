## Uso e continuidade

O histórico Git começa nesta importação. Os históricos editoriais existentes nos documentos foram preservados; versões técnicas anteriores da Biblioteca não foram importadas.

Notas de lotes antigos são documentação histórica, não orientação automaticamente vigente. Por exemplo, Educa_AI_EP03_101-120_Registro_de_Producao.md usa o roteiro 1.0; consultar o registro mestre e a revisão posterior antes de usar esse lote. Decisões posteriores em conversa podem ainda precisar de consolidação nos documentos; esta migração não as aplica silenciosamente.
